# Описание файлов лабораторной работы

Программа читает Online Retail, удаляет полные повторы, отбирает допустимые
продажи и формирует топ-5 товаров, суммы заказов и показатели клиентов.

## Java-код

Все классы находятся в `src/main/java/ru/example/`.

| Файл | Что делает |
|---|---|
| `RetailApp.java` | Точка входа `main`: запускает загрузку, валидацию, аналитику и экспорт, выводит количество обработанных строк. |
| `DatasetLoader.java` | Читает CSV в Windows-1252, удаляет дубликаты по восьми исходным полям до преобразования типов, создаёт объекты `Transaction`. Крупные наборы хранит на диске через Spark. |
| `CsvParser.java` | Разбирает CSV: учитывает запятые и переносы строк внутри кавычек, а также удвоенные кавычки. Сообщает об ошибке при незакрытой кавычке. |
| `Transaction.java` | Представляет одну позицию документа. Хранит восемь полей источника, убирает внешние пробелы, преобразует количество в `long`, цену в `BigDecimal`. Метод `lineTotal()` вычисляет количество × цену. |
| `DatasetValidator.java` | Определяет допустимые продажи и кредиты, исключает служебные коды из товарного рейтинга, проверяет отсутствие нескольких известных клиентов у одного документа. |
| `ProductAnalytics.java` | Суммирует количество и стоимость по коду товара, считает уникальные заказы, выбирает самое частое непустое название. Возвращает пять товаров по количеству, при равенстве сортирует по коду. |
| `ProductMetrics.java` | Хранит название товара, проданное количество, число заказов и сумму. Содержит небольшие методы сложения сумм и присоединения названия и числа заказов. |
| `CustomerAnalytics.java` | Собирает суммы заказов по клиенту и номеру документа, затем число заказов и общую сумму клиента. Добавляет известных клиентов без допустимых продаж с нулевыми показателями. |
| `CustomerMetrics.java` | Хранит число заказов и сумму клиента. Вычисляет средний чек как сумму / число заказов, округляя до двух знаков HALF_UP; при отсутствии заказов возвращает `null`. |
| `ResultWriter.java` | Сортирует заказы и клиентов, экранирует CSV-поля, форматирует суммы и записывает три каталога результатов с заголовками. |

Порядок выполнения: `RetailApp` → `DatasetLoader` → `DatasetValidator` →
`ProductAnalytics` и `CustomerAnalytics` → `ResultWriter`.

`Transaction` — позиция документа, а не весь заказ. Поэтому для среднего чека
сначала складываются позиции заказа, затем суммы заказов клиента.

## Конфигурация и документация

| Файл | Что делает |
|---|---|
| `Dockerfile` | Компилирует Java-классы, собирает JAR, копирует датасет и задаёт запуск через `spark-submit` в режиме `local[1]`. |
| `compose.yaml` | Задаёт сборку и запуск контейнера, подключает локальный каталог `output` для выгрузок. |
| `pom.xml` | Задаёт Java 17, версию Spark и зависимости для Maven и IDE. |
| `.dockerignore` | Исключает ненужные файлы из контекста сборки Docker. |
| `.gitignore` | Исключает сгенерированные данные проверки качества, Python-кэш и `target` из Git. |
| `data.csv` | Исходный датасет Online Retail. |
| `DE_memo.md` | Подробный контракт обработки, формулы, допущения и требования к качеству. |
| `eds.ipynb` | Исследовательский ноутбук с анализом датасета и контрольными результатами. |
| `README.md` | Описание задания, правила расчёта, команды запуска и результаты предыдущего прогона. |
| `PROJECT_STRUCTURE.md` | Это описание назначения файлов. |

## Результаты Java-программы

- `output/top5_products.csv` — топ-5 товаров.
- `output/orders.csv` — суммы заказов известных клиентов.
- `output/customer_metrics.csv` — число заказов, общая сумма и средний чек клиентов.

Spark создаёт каталоги с `part-*` и `_SUCCESS`, а не обычные файлы с этими
именами. `target/` содержит локальные результаты компиляции.

## Границы текущей реализации

Основные Java-витрины используют gross: кредиты не вычитаются из продаж.
Строки без клиента остаются в товарных расчётах. Служебные позиции исключаются
из рейтинга товаров, но входят в допустимые начисления клиента.

Валидация базовая: число полей, числовые типы, заполненность кода и даты,
номер документа, знаки количества и цены, конфликты клиентов. Дата остаётся
строкой; проверки её формата, net-витрин и экспорта причин отклонения в Java
пока нет. Контракт `DE_memo.md` шире текущей реализации.

После упрощения Java-кода проверена локальная компиляция под Java 17.
Серверный прогон упрощённой версии не выполнялся; числа в README относятся
к предыдущему запуску.
