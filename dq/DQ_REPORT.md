Файл сгенерирован `python dq/dq_check.py data.csv`. DQ пересобирает датасет отдельным кодом по контракту `DE_memo.md` и сверяет цифры с `eds.ipynb`.

## 1. Итог

- Проверок: **82**, ошибок ERROR: **0**. Все 17 контрольных значений совпали с ноутбуком DE.
- Исходник 541 909 строк → после дедупликации 536 641 → продажи 524 877, кредиты 9 251, исключено 2 513.
- Клиентов 4 372: с продажами 4 338, без продаж 34 (средний чек пустой).
- **Главный риск:** топ-5 gross на 1–2 местах держат два заказа, полностью отменённые через 12–16 минут (23843, 23166). На защите показывать gross и net рядом.
- **Находка по файлу:** `data.csv` в репозитории хранится с LF, а не CRLF, поэтому его SHA256 не совпадает с зафиксированным в ноутбуке. Содержимое то же (раздел 2).

## 3. Найденные проблемы

Доля считается от всех 541 909 строк исходного файла. Одна строка может попасть сразу в несколько проблем, поэтому доли не складываются.

| Проблема | Строк | Доля от всех строк, % | Что делаем |
|---|---|---|---|
| Нет номера клиента (CustomerID) | 135 080 | 24,93 | Для топа товаров оставляем, в расчёт по клиентам не берём |
| Лишние пробелы в названии товара | 113 452 | 20,94 | Убираем пробелы |
| У одного товара несколько разных названий | 112 742 | 20,80 | Товар определяем по коду, название берём самое частое |
| Отменённые заказы (номер начинается с C) | 9 288 | 1,71 | В продажи не берём, вычитаем только в топе net |
| Одна и та же строка повторяется | 5 268 | 0,97 | Удаляем копии, оставляем одну строку |
| Доставка, комиссии, скидки вместо товара | 2 946 | 0,54 | В топ товаров не берём, в сумму клиента включаем |
| Цена 0 | 2 515 | 0,46 | Убираем: это подарки и списания, а не продажи |
| Нет названия товара | 1 454 | 0,27 | Отдельно не чистим: у всех этих строк цена 0, они уходят по правилу «Цена 0» |
| Отрицательное количество в обычном заказе | 1 336 | 0,25 | Убираем: это складские списания, а не возвраты |
| Корректировка долга (номер начинается с A) | 3 | меньше 0,01 | Убираем: это бухгалтерская запись, а не продажа |
| Отрицательная цена | 2 | меньше 0,01 | Убираем |

Служебные коды, которые не считаются товаром: AMAZONFEE, B, BANK CHARGES, C2, CRUK, D, DOT, M, POST, S и подарочные сертификаты gift_*. Коды PADS и DCGS* — обычные товары.

## 4. Правила (по DE_memo.md)

1. Дедупликация по всем 8 исходным полям до trim и приведения типов.
2. Trim, пустые значения → NULL; Quantity → целое, UnitPrice → точная цена (1e-4 GBP), дата `%m/%d/%Y %H:%M`.
3. **Продажа:** InvoiceNo = 6 цифр, Quantity > 0, UnitPrice > 0, дата и StockCode заполнены.
4. **Кредит:** InvoiceNo = C + 6 цифр, Quantity < 0, UnitPrice > 0.
5. Остальное (нулевые и отрицательные цены, A-документы, Quantity < 0 без C) — в `excluded` с причиной.
6. Топ-5 gross: сумма Quantity по товарным продажам, все страны, с клиентом и без.
7. Топ-5 net: gross − единицы в кредитах.
8. Клиенты: все известные ID; заказы = уникальные InvoiceNo продаж; сумма включает доставку и Manual; чек = сумма / заказы, пусто при 0 заказов.

## 11. Сверка с аналитиком

Эталонные витрины DQ: `dq/reference/top5_gross.csv`, `top5_net.csv`, `customer_metrics.csv`. Витрину аналитика сверяем функцией `reconcile()`:

```python
import pandas as pd, sys
sys.path.insert(0, 'dq')
from dq_check import reconcile
ref = pd.read_csv('dq/reference/customer_metrics.csv', dtype={'CustomerID': str})
mine = pd.read_csv('exports/customer_metrics.csv', dtype={'CustomerID': str})
for c in reconcile(mine, ref):
    print(c['ok'], c['check'])
```
